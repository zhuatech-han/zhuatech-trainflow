# TrainFlow 操作手册

## 1. 建立培训岗位

管理员建立部门、培训管理员、培训复核员和学员账号。学员采用SELF范围，只看到本人分配记录。管理者采用DEPARTMENT或ALL范围。角色功能权限与范围分别生效；ALL并不允许替别人考试。课程发布人不能是版本编制人。实操复核人不能是学员或本任务分配人，因此实操培训通常需要三个独立岗位账号。

## 2. 编制与发布

课程版本选择新建，填写实例唯一编号、分类、部门、正文、通过分数、最多次数、有效天数及是否需要实操。每个版本2–30题，每题4个不同选项，选择一个标准答案。版本编制人可编辑或删除未发布草稿；其他人员不可代改草稿。编号和部门创建后冻结。

复核员进入本人工作台的课程发布待审，核对内容与评分规则，填写审核依据后批准发布。发布后不再修改正文或答案。归档停止新分配，已有任务继续使用原版。创建新版复制内容为新草稿，每个编号最多一份未发布新版；新版本发布时旧发布版本归档。

## 3. 分配与学习

培训管理员在已发布课程详情点击分配培训。选择启用、有本人学习权限且部门匹配的学员；有实操时选择有复核权限且与学员和分配人独立的复核员。截止日含当天，范围为今日至730天后。同版未完成或有效培训不能重复分配。

学员工作台打开课程，阅读正文，点击确认阅读并开始考试。确认不是阅读时长证明。完整回答每道题再提交；得分由服务器按正确比例向下取整数。失败但尚有次数时可重考；达到分数后无实操课程直接合格，有实操课程进入待复核。最终未通过的任务保留考试历史，管理员可重新分配新任务。

## 4. 实操与能力

指定复核人在工作台打开实操待办，现场按课程内容核对后填写证据引用，选择通过或未通过。系统不代替实操。未通过结束任务，不清除笔试成绩。通过记录服务器时间及有效期。含当天的有效天数例如1天意味着当天有效；过期后显示已到期，可以重训。

超过任务截止日不能继续阅读确认、考试和实操复核。管理员填写原因取消旧任务后重新分配。有效能力可有理由撤销，原成绩、通过时间及截止日仍保留。能力撤销不是删除。旧版成绩不会因新版本变更自动失效或自动转换，是否安排新版培训由培训管理员决定。

## 5. 查找与导出

课程和学习列表按课程名或编号搜索，筛选状态，按最新或最早分页查看。统计显示范围内各状态、逾期未完成任务及未来参数天数内到期的有效能力。导出当前记录JSON沿用详情权限，学员导出不含标准答案。操作审计最多展示最近1,000条，记录对象与行为，不写密码或答题载荷。
