# TrainFlow 验证说明

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。

后端TrainPolicyTest覆盖完整/部分评分、缺失与越界答案、上海日期有效边界、撤销优先、陈旧版本。TrainIntegrationTest使用真实Spring请求、事务和迁移，覆盖独立发布、冻结正文、新版原任务隔离、SELF及部门权限、答案屏蔽、学习确认、次数耗尽、自动资格、指定复核、到期重训、逾期、撤销、精确重试、并发考试与会话失效。

前端测试覆盖CSRF与会话请求、业务错误、发布与实操按钮的独立性和本人关系。格式Prettier/Spotless，静态ESLint，构建Vite/Maven。Docker构建保留这些门禁，不跳过后端测试。

MySQL验收使用独立全新数据库卷：健康、登录、分配、一次失败与一次成功考试、独立实操通过、新版发布不改变旧题与成绩、权限及导出屏蔽、迁移、重启后成绩持久化。`scripts/smoke.py` 只允许本机，不使用真实员工；运行前确认专用空测试库，记录均带TEST。浏览器验收实际学习、课程编辑、账号权限、统计和手机布局。测试凭据及输出不纳入源码。

具体命令见README。线上支付、课件上传、实物设备、监考和法定认证不属于已实现能力，也不声称通过这些验收。

当前自动化用例：后端38项（规则8项、集成30项），前端8项；MySQL专用全新库业务检查76项，重启持久化检查11项。
