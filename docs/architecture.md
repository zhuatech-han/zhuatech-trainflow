# TrainFlow 架构与持久化

知华科技（上海如静知华信息科技有限公司） · https://www.zhuatech.cn/ · 微信 zhuatech / zhuatech2。

Vue3 → Nginx同源代理 → Spring Boot4 / Security / JPA → MySQL8。Flyway V1身份管理，V2培训域、V3题目变更修订计数，JPA validate。后端Java21，前端Node24.19.0+。

Course是按familyCode/edition唯一的课程版本；Question固定四选一题目及标准答案。Enrollment引用课程版本、学员、分配人、独立复核人，保存截止日、状态、尝试次数、最高分、阅读时间、通过时间与有效日。ExamAttempt只追加，保存考试顺序、实际提交选项和服务器成绩。FlowEvent与AuditEvent记录流程事实和简短操作，CommandRecord保存UUID、操作者载荷摘要和返回对象ID。

草稿可编辑，发布后冻结。新发布版本归档旧发布版本，但不转移已有任务。题目不是共享的全局题库，改新版不能改变旧题及旧评分。完成培训后，有效期按上海业务日期包含首末日。状态过期计算不修改历史状态；撤销与到期分别显示。学习阅读确认、人工实操证据不是监考或法定认证。

所有写操作包括身份修改共用基础Department1行锁，事务隔离READ_COMMITTED，锁后刷新操作者与实时角色。业务版本拒绝旧页面，UUID摘要保护精确重试；并发考试一个版本只接受一次。流转、考试、事件和审计同事务提交。密码变更及账号停用使原会话在后续请求失效。

列表在数据库执行范围和分页；SELF通过Enrollment限制课程访问，人员选项只本人；部门和全范围采用数据库条件。详情和导出复用范围，学员标准答案在DTO层删除。选择、待办、统计为最多10000条有界查询，超过统计限制拒绝；审计只读最近1000条。单任务最多10次考试，课程最多30题，无任意文件上传。当前共享写锁面向小规模学习实例，不提供大规模并发承诺。
